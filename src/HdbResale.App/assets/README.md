# OneMap attribution logo

`onemap-logo.png` is the unchanged official 32×32 PNG downloaded on 2026-10-03
from <https://www.onemap.gov.sg/web-assets/images/logo/om_logo.png>.
SHA-256: `657db347017b13e71bc4942afbe985566052446b13433f2dd5492e92fce34f16`.

The [OneMap map documentation](https://www.onemap.gov.sg/docs/maps/) requires
this logo with linked “OneMap © contributors | Singapore Land Authority” text.
It is bundled solely for that attribution, preserving the graphic/copyright
notice; see [OneMap Terms of Use](https://www.onemap.gov.sg/legal/termsofuse.html).
Bundling keeps attribution available when previously cached tiles are displayed
without network access. No raster map tiles or offline tile bundle are included.

# Map control icons

`icons/zoom-in.svg`, `icons/zoom-out.svg` and `icons/go-home.svg` are original,
minimal stroke icons written for this project (GPL-3.0-or-later like the application
source; no third-party artwork). They are only a fallback: the controls first ask the
platform icon theme for `zoom-in`, `zoom-out` and `go-home`, so KDE/GNOME show their own
icons and macOS/Windows (which have no freedesktop theme) use these.
